# Norse.Identity.Web.Server

The explicit-write `NorseUserStore` (Identity's store interfaces implemented directly, with no EF change tracker), `NorseUserManager`, `NorseSignInManager`, the `SignInManager` `.Outcome` view, and `ErasureService` over the entity model and `NorseIdentityDbContext` that `Norse.Identity.EntityFramework` carries — plus, since PR #27, `IAuthenticationService`'s gRPC implementation over that store. The eleven commands — `LoginCommand`/`RegisterCommand`/`EmailExistsCommand`/`LogoutCommand` and the anonymous tier's `TwoFactorSignInCommand`/`RecoveryCodeSignInCommand`/`ForgotPasswordCommand`/`ResetPasswordCommand`/`ConfirmEmailCommand`/`ConfirmEmailChangeCommand`/`ResendEmailConfirmationCommand` — wrap Heimdall's pure wire DTOs (Asgard's `CommandRequest<TRequest,TResponse>`) to give them mediator identity and an `[Authorize]` policy the wire records themselves never carry; handlers work entirely in `Outcome<T>` (Asgard's mediator law), reach Identity and OpenIddict only through the `.Outcome` views (`Norse.Identity.Outcomes`, plus the `SignInManager` view here), and return the exact wire result type directly — the service itself is a bare hydrate-and-send forwarder, no mapping switches. `AddNorseAuthenticationService(connectionString)` is the single composition-root entry point a host calls to pull in the `DbContext`, ASP.NET Core Identity (with the `NorseSignInManager` override), the generated mediator handler/validator-adapter/dispatch registration, and the service itself.

Always runs inside an HTTP context, bound into Yggdrasil's `Hosting.Web.Server` process — never referenced from WASM or MAUI. Also still carries what remains of the original Yggdrasil-scaffolded Razor page tree (`Components/Pages/**`): the `/Account/Manage` tree and the external-login callback. The anonymous-tier pages are already gone, replaced by gRPC operations on `AuthenticationService`; the rest are being migrated out to Heimdall's `AuthN.Components`/`AuthN.Components.FluentUI` component by component, not all at once, so expect this project's UI surface to keep shrinking.

Part of the [Norse Architecture](https://github.com/NorseArchitecture) platform.
